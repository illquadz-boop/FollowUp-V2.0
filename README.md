# FollowUp v2.0

> **2026-09-10 실제 API 연동 추가:** 기본 실행은 EC2 백엔드 연결 모드입니다. [실제 연동 구조·실행 방법·검증 결과](docs/LIVE-API-INTEGRATION.md)를 먼저 확인하세요. 아래 기존 데모·정적 배포·세션 계약 설명은 초기 v2.0 기록입니다. 현재는 서버 중계 경로가 필요하며 정적 파일만으로 배포할 수 없습니다. 회의 참여자 변경과 업무 담당자/마감일 해제는 백엔드 결함이 확인되어 서버 수정이 필요합니다.

첨부된 `FollowUpApp.jsx`의 원본 로고와 페이지 구성을 바탕으로 만든 회의·후속 업무 관리 프론트엔드입니다. React + TypeScript, Vite/Vinext, React Router, TanStack Query, React Hook Form, Zod, Axios를 사용합니다. 백엔드 서버는 포함하지 않습니다.

패키지 버전은 `2.0.0`, Git 릴리스 태그는 `v2.0`입니다. 이번 버전은 구현된 프론트엔드 소스와 백엔드 통합 문서를 함께 정리한 버전이며, Spring Boot·MySQL·실제 AI가 연결된 풀스택 완성본을 의미하지 않습니다.

## 바로 사용하기

홈 화면의 **데모 둘러보기**로 샘플 프로젝트에 들어갈 수 있습니다. 회원가입으로 별도의 빈 작업 공간을 만들 수도 있습니다.

1. 프로젝트에서 **새 회의**를 선택합니다.
2. 제목·날짜·참여자와 회의록을 입력하거나 `.txt` / `.md` 파일을 불러옵니다.
3. 분석 결과의 결정 사항·일정·업무를 수정합니다.
4. 업무 담당자와 기한을 확인하고 **확정**합니다.
5. 업무 보드에서 상태를 이동하거나 상세 화면에서 수정합니다.
6. 다음 회의를 만들면 이전 회의의 미완료 업무가 연결됩니다.

기본 체험 모드는 기기·브라우저별 로컬 데이터입니다. 실제 팀원에게 공유되거나 이메일이 발송되지 않습니다. 호스팅 주소와 localhost의 저장 데이터도 서로 독립적입니다. 중요한 실제 회의록이나 실제 서비스 비밀번호를 체험 모드에 입력하지 마세요.

## 포함된 화면과 기능

- 랜딩: 원본 브랜드 자산, 제품 미리보기, 기능·요금제 섹션, 스크롤 등장 효과, 반응형 레이아웃, 모션 감소 설정 대응.
- 인증: 회원가입, 로그인, 로그아웃, 입력 검증, 이메일 중복 확인, 내 정보 수정.
- 작업 공간·프로젝트: 목록, 생성, 수정, 삭제, 구성원 관리.
- 대시보드: 업무 상태별 집계, 임박·지연 업무, 최근 회의, 회의 이후 변화, 구성원별 진행률.
- 회의: 목록·검색, 등록·조회·수정·삭제, 임시 저장, 파일 불러오기, 초안 분석·재분석, 이전 미완료 업무 연결.
- 검토: 결정 사항·일정·후속 업무의 추가·수정·삭제, 담당자·기한·우선순위·추천 이유 수정, 검토 후 확정.
- 업무: 보드/목록, 드래그 이동, 상세 수정·삭제, 검색 및 담당자·상태·우선순위·기한 필터, 원본 회의 연결.
- 공통: 로딩·빈 화면·오류·재시도·성공 알림, 삭제 확인, 중복 제출 방지, 키보드 접근 가능한 폼과 대화상자.

요금제는 첨부 디자인을 재현하는 안내 화면이며 실제 결제를 수행하지 않습니다. 알림 메일, 실제 LLM 호출, 회고 자동 생성은 포함하지 않습니다.

## 로컬 실행

Node.js 22.13 이상과 npm이 필요합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 Local 주소를 엽니다. 포트가 사용 중이면 개발 서버가 다음 포트를 선택합니다.

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

정적 웹사이트 결과는 `dist/client/`에 생성됩니다. 로그인 이후 경로는 해시 라우팅(`/#/p/...`)이므로 일반 정적 호스팅에서도 새로고침이 가능합니다. 실제 서비스에서는 HTTPS를 사용하세요.

## 백엔드 연결

`.env.example`을 참고해 `.env.local`에 다음 값을 설정하고 다시 실행/빌드합니다.

```dotenv
VITE_DATA_MODE=api
VITE_API_BASE_URL=http://localhost:8080/api
```

`VITE_` 값은 브라우저에 공개됩니다. API 키·비밀키를 넣지 마세요. API 모드는 서버가 없어도 데모 데이터로 조용히 대체하지 않으며 오류를 명시적으로 보여줍니다.

위 주소는 로컬 직접 연결 예시입니다. 실제 연결에는 CSRF 초기화와 서버 CORS·세션 설정이 추가로 필요합니다. 운영에서는 같은 출처의 `/api`를 권장하며, 자세한 프록시 설정과 필요한 프론트 보완은 [통합 가이드](docs/BACKEND-INTEGRATION.md)를 따르세요. 환경변수만 바꿔서 보안 연결까지 완료되는 것은 아닙니다.

자세한 엔드포인트, 응답 형태, 인증 및 데이터 정합성 조건은 [API 연결 안내](docs/API-CONTRACT.md)에 있습니다. 실제 AI 분석은 서버가 처리하고 프론트엔드는 결과의 검토·확정을 담당합니다.
