# FollowUp v2.0 — 프론트엔드 및 백엔드 통합 가이드

## 소개

회의의 결정 사항을 실제 후속 업무로 연결하는 FollowUp의 프론트엔드 소스 배포본입니다. 첨부된 원본 로고와 페이지 구성을 반영하고, 미니멀한 화면과 부드러운 모션을 적용했습니다.

패키지 버전: `2.0.0` · Git 태그: `v2.0`

## 제공 기능

- 작업 공간·프로젝트·구성원 관리.
- 회의 작성·조회·수정·삭제, `.txt`와 `.md` 회의록 불러오기.
- 분석 초안의 결정 사항·일정·업무 추가·수정·삭제와 최종 확정.
- 후속 업무 보드·목록·검색·담당자·상태·우선순위·기한 필터.
- 다음 회의에 이전 미완료 업무 연결.
- 업무 현황·임박·지연·구성원별 진행률 대시보드.
- 입력·응답 검증, 오류 처리, 로컬 임시 저장, 중복 제출 방지.

## v2.0 정리 내용

기존 구현을 버전 고정된 소스로 정리하고, README·변경 내역·릴리스 설명·Spring Boot + MySQL 통합 가이드·GitHub 업로드 절차를 함께 제공합니다. 이번 버전에서 실제 백엔드를 구현하거나 연결한 것은 아닙니다.

## 실행

Node.js 22.13 이상에서 다음 명령으로 시작합니다.

```sh
npm ci
npm run dev
```

홈 화면에서 데모로 진입해 회의·업무 관리 흐름을 사용할 수 있습니다. API 모드로 전환하려면 README와 백엔드 통합 가이드를 먼저 확인하세요.

## 검증 및 제한

- 데이터 흐름·HTTP 어댑터 자동 검사 10개를 포함합니다.
- 실제 브라우저별 인터랙션, 실제 Spring Boot API, 다중 사용자 운영 검증은 별도입니다.
- 기본 데이터와 계정은 기기 내 체험용입니다. AI 분석은 로컬 규칙 기반이며 실제 LLM을 호출하지 않습니다.
- 실제 인증·AI·데이터 공유·메일·결제는 서버 구현이 필요합니다.
- 기존 의존성 보안 경고와 운영 전 점검 목록은 `docs/VERIFICATION.md`에 기록했습니다.

## 안내

API 키나 실제 회의록을 소스에 포함하지 마세요. GitHub 저장소의 공개 범위와 기존 비공개 데모 사이트의 공개 범위는 서로 독립적입니다. GitHub 릴리스 생성만으로 데모 사이트가 다시 배포되지는 않습니다.
