# 검증 기록과 운영 전 점검

## 자동 검사 범위

`npm test`는 브라우저를 클릭하는 테스트가 아니라 데이터 저장소·분석·HTTP 어댑터에 대한 자동 검사입니다.

1. 회의 저장 → 분석 → 초안 수정·복원 → 확정 → 업무 생성 → 다음 회의 연결.
2. 병렬 확정 요청의 업무 중복 방지, 완료·재개 시각의 일관성.
3. 잘못된 입력, 분석 실패, 오래된 초안, 원문 변경 시 데이터 보존.
4. 구성원 제거, 업무·회의·프로젝트 삭제의 참조 일관성.
5. 회원가입·이메일 중복·로그인 실패·로그아웃·다른 계정의 프로젝트 접근 차단, 평문 비밀번호 미저장.
6. 오늘·임박·지연·완료 및 유효하지 않은 날짜 경계.
7. 체험 분석의 불명확한 담당자 처리, 상대 날짜 해석.
8. 저장 공간 부족 시 기존 데이터 보존.
9. HTTP 응답 형식 검증·data 래퍼·204·확정 멱등 키.
10. 네트워크·타임아웃·인증 오류 변환.

실제 등록된 테스트 케이스 수는 10개이며 일부 케이스가 위 항목을 함께 검증합니다. TypeScript 검사와 제품 소스 정적 검사도 제공합니다. 정적 검사에서는 수정하지 않은 외부 UI 카탈로그(`components/ui`)와 그 모바일 훅을 제외하며, 원본 PNG 로고의 img 사용은 정적 호스팅에 맞춰 명시적으로 허용합니다.

## 아직 검증하지 않은 범위

- 브라우저별 실제 클릭·드래그·터치·키보드 동작, 화면 크기별 육안 검사, 스크린리더 테스트. 반응형 스타일과 접근성 속성은 구현했으나 브라우저 자동화/시각 검증을 수행했다고 주장하지 않습니다.
- 실제 Spring Boot 서버의 인증 쿠키, CORS/CSRF, API 응답, LLM 분석, 여러 사용자 동시 수정. 백엔드가 제공되지 않아 HTTP 모의 어댑터로만 계약을 검사했습니다.
- 선택적 WebMCP 도구 2개(`list_followup_tasks`, `update_followup_task_status`)는 기능 감지 및 정리 처리를 포함하지만 지원되는 호출 환경이 없어 등록·실행 계약 검증은 미수행입니다. 미지원 브라우저에서도 일반 UI는 영향을 받지 않습니다.

## 의존성 보안 점검

2026-09-09 로컬 `npm audit`는 스캐폴드에서 가져온 개발/서버 도구 의존성을 포함해 11건(높음 8, 보통 2, 낮음 1)을 보고했습니다. 핵심 경로에는 vinext의 image-size, React Server Components, Vite, undici, esbuild 등이 포함됩니다. 기반 도구를 강제 일괄 업그레이드하지 않고 고정 버전을 유지했습니다.

이 결과물은 `dist/client`만 게시하는 프론트엔드 정적 배포이며, 생성 중간물인 서버 번들·개발 서버·Server Functions는 게시하지 않습니다. 그렇다고 의존성 전체가 보안 검증을 마쳤다는 뜻은 아닙니다. 실서비스 통합 전에 해당 도구의 호환 패치 버전을 적용하고 다시 빌드·테스트·감사를 수행하세요. 개발 서버를 외부 공개 서버로 사용하지 마세요.
